# ORS demand forecasting

## Problem statement
Forecast weekly ORS demand in one district, 4 weeks ahead,
using past demand and weather data. Success means a lower WAPE
than the same-week-last-year baseline.

## Decisions
- Product: ORS
- Region: Pune district
- Frequency: weekly
- Horizon: 4 weeks
- Metric: WAPE vs same-week-last-year baseline
